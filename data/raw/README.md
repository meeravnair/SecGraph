# Raw CERT Dataset Storage

Place your downloaded Carnegie Mellon University SEI CERT Insider Threat Test Dataset CSV files here:

- `logon.csv`
- `file.csv`
- `device.csv`
- `email.csv`
- `http.csv`
- `insiders.csv` (Answer Key)

Download official dataset from: https://www.sei.cmu.edu/library/insider-threat-test-dataset/
